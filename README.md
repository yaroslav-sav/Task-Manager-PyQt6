# Task-Manager-PyQt6

desktop-приложение на PyQt6 для создания задач.

## Возможности

- Ввод названия задачи (однострочное поле)
- Ввод описания задачи (многострочное поле)
- Выбор приоритета: Low / Medium / High (радиокнопки)
- Дополнительные настройки: Important, Send notification
- Кнопка **Create task** — собирает данные из формы и выводит результат в окно
- Кнопка **Clear** — очищает форму и сбрасывает статус
- Статус приложения: `Ready` и `Task created` после создания задачи
- Валидация: нельзя создать задачу без названия
